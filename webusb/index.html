    Help

    Prepare DJI FPV Goggles V2
    1. Power on the goggles, link the air unit (DJI Air Unit, Caddx Vista or O3) and confirm a live camera picture in the goggles.
    2. Select the goggles mode matching your air unit.
    3. Connect the goggles' USB-C port to this device with a USB data cable. Close other goggles apps, including the desktop DJI Goggles Bridge.
    4. Click Connect goggles and choose the DJI device.

    The picture includes any menus or OSD shown by the goggles. There is no audio. If the goggles send no keyframes, the view starts grey and fills in within a second or two as the stream refreshes.

    Windows: install WinUSB with Zadig (once)
    1. Download Zadig and run it.
    2. Enable Options > List All Devices.
    3. Select Vision / Bulk Interface (Interface 3 / MI_03), USB ID 2CA3 001F. Verify that exact interface.
    4. Install or replace its driver with WinUSB. Leave the other interfaces alone.

    The desktop bridge app uses the same WinUSB setup, so both keep working.

    Linux: allow USB access

    Create /etc/udev/rules.d/70-dji-goggles.rules with:

    SUBSYSTEM=="usb", ATTR{idVendor}=="2ca3", ATTR{idProduct}=="001f", MODE="0660", TAG+="uaccess"

    Then run sudo udevadm control --reload-rules and replug the goggles.

    macOS and Android

    macOS needs no driver setup. On Android, use Chrome and a USB-C data cable or OTG adapter; the phone must act as the USB host. Android and other V2 pairings have not been verified on hardware yet.

    DJI Goggles 3, Goggles 2 and other headsets

    DJI Goggles 3 send video through a USB network (RNDIS) interface. Browsers deliberately block that interface class for WebUSB, so Goggles 3 only work with the desktop DJI Goggles Bridge app. DJI Goggles 2, analog AV-IN, the DJI FPV drone and Avata are not supported here.

    Browsers, recording and OBS

    WebUSB and WebCodecs need Chrome, Edge or another Chromium browser on desktop or Android. Firefox and Safari do not support WebUSB.

    Record saves an H.264 (.h264) file that VLC, ffplay and ffmpeg can open. To make an MP4: ffmpeg -framerate 60 -i input.h264 -c copy output.mp4 (use your goggles' frame rate).

    For OBS, add a Window Capture of this window, then use fullscreen or install the app to remove browser controls.

    Everything runs locally in your browser: video never leaves this device.
